# Agentes, skills e integraciones

- **Claude Code** (app de escritorio): lectura y escritura de archivos, ejecución de comandos (Maven, npm, Docker, git) y navegador integrado para comprobar la interfaz.
- **Subagentes:** no se usaron en la Fase 0.
- **Skills y MCP:** no se usaron skills propias del proyecto. Hay conectores disponibles en el entorno (Trello, Figma, Notion) que no se han usado; Trello podría servir para el tablero de tareas cuando se decida.
- **Skills de diseño (rediseño «Partido nocturno»):** instaladas localmente (no versionadas) desde sus repositorios públicos: Impeccable (`pbakaus/impeccable`), Emil Kowalski (`emilkowalski/skills`: emil-design-eng y las de animación), taste-skill (`Leonxlnx/taste-skill`), css-animations (`TheLobbi/claude`), ui-animation (`mblode/agent-skills`) y animation-designer (`FerroxLabs/murage`). Se usaron sus reglas (jerarquía, movimiento, accesibilidad, anti-«AI slop») leyendo los archivos; sus scripts no se ejecutaron.
- **Figma (MCP):** se usó para probar la paleta y una versión minimalista de la portada antes de tocar el código.
